# Fullstack Projects

A collection of web development and fullstack projects:

- **`crud-app`**: Node.js / Express CRUD application with MongoDB/database models.
- **`job-application`**: Fullstack job application portal with frontend and backend services.
- **`nuxt-layout`**: Nuxt 3 project showcasing layouts, page routing, and server endpoints.
- **`state-management`**: Vue 3 application demonstrating state management using Pinia.
- **`vue-directives`**: Vue 3 project exploring built-in and custom Vue directives.
